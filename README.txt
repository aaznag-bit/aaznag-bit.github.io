Abdellah Aznag — local personal website

Open index.html in your browser. No install, build step, or internet connection is needed for the page itself. Paper, CV, institution and profile links open their original online destinations.

To run a local web server from this directory:
  python3 -m http.server 8000 --bind 127.0.0.1
Then visit http://127.0.0.1:8000

Edit index.html to update your biography, publications and links.
Edit styles.css to change the appearance.
assets/portrait.jpg is the original photo from your Google Site.
